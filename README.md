## ✨ Fitur Utama

* **Compact Circular Overlay**: Menampilkan bulatan status bar sempurna di sudut kanan atas layar.
* **Custom Size Control**: Slider pengatur ukuran diameter bulatan status bar (20–100 dp).
* **Green Battery Arc**: Garis busur setengah lingkaran atas warna Hijau () melengkung dinamik mengikuti sisa persentase baterai.
* **Blue GSM Signal Arc**: Garis busur setengah lingkaran bawah warna Biru ().
* **Conditional Wi-Fi Bar**: Otomatis menyembunyikan ikon Wi-Fi saat terputus, dan menampilkan bar sinyal bertingkat (1-4) saat tersambung.
